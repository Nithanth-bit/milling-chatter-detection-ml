# Machine Learning-Based Chatter Detection in Milling Operations

An interactive, research-grade Industrial AI web application transforming a Production Engineering research project on simulated milling chatter detection into a reproducible ML pipeline and deployable Streamlit analytics platform.

**Data Source:** Digital Machining Database for Machine Learning (*Schmitz, T. & Smith, K. S., Machining Dynamics: Frequency Response to Improved Productivity, 2nd Ed., Springer, 2019*).  
**Important Scope Notice:** This is a **simulated-data research prototype**. It does not claim shop-floor CNC hardware validation or real-time edge deployment.

## Step 1 — Local Setup

```bash
cd chatter-detection-app
python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1
# macOS / Linux
source .venv/bin/activate

pip install --upgrade pip
pip install -r requirements.txt
```

## Step 2 — Run Phase 2 Training (Generates Real Model & Metrics)

This repository intentionally ships **without fabricated metrics**. Run `train_pipeline.py` once on the machine holding your HDF5 folders:

```bash
# Option A (Recommended): Strongest cross-configuration benchmark (Datasets 1, 15, 19)
python train_pipeline.py --experiment d1_d15_d19

# Option B: Initial 394-cut benchmark (Datasets 1, 2, 3)
python train_pipeline.py --experiment d1_d2_d3

# Option C: Custom local folder paths
python train_pipeline.py \
  --time-dir "C:\path\to\dataset 1,15,19" \
  --boundary-dir "C:\path\to\stability boundary of 1,15, 19" \
  --datasets 1 15 19

# Option D: Train directly from an already-extracted validated CSV
python train_pipeline.py --csv path/to/processed_features.csv
```

Running `train_pipeline.py` automatically writes:
- `data/processed_features.csv`
- `data/stability_boundaries/stability_boundary{ds}.h5`
- `data/samples/sample_stable_cut.csv` and `sample_chatter_cut.csv`
- `models/final_model.joblib`, `models/model_metadata.json`, `models/evaluation_results.json`

## Step 4 — Upload to GitHub

> **Important:** Commit `models/`, `data/processed_features.csv`, `data/samples/`, and the small `data/stability_boundaries/stability_boundary*.h5` files so Streamlit Cloud works standalone. **Never commit raw `time*.h5` folders** (they are already excluded in `.gitignore`).

```bash
git init
git add .
git commit -m "Initial release: Milling Chatter Detection ML Research Platform"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/milling-chatter-detection-ml.git
git push -u origin main
```

## Step 5 — Deploy Publicly on Streamlit Community Cloud

1. Visit **[https://share.streamlit.io](https://share.streamlit.io)** and sign in with your GitHub account.
2. Click **Create app** -> **Yep, I have an app**.
3. Configure deployment settings:
   - **Repository:** `<YOUR_USERNAME>/milling-chatter-detection-ml`
   - **Branch:** `main`
   - **Main file path:** `app.py`
4. Click **Deploy!** Streamlit Community Cloud installs `requirements.txt` and launches your public URL (`https://<your-app-name>.streamlit.app`).
